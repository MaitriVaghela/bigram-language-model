## Overview

This project implements a Bigram Language Model using character-level tokenization. The model learns the probability of each character given the previous one, then uses that distribution to autoregressively generate new text.

The bigram assumption factorizes the joint probability of a sequence as:

$$P(x_1, x_2, \ldots, x_n) = \prod_{i=1}^{n} P(x_i \mid x_{i-1})$$

Each token depends only on the immediately preceding token — simple, interpretable, and a great foundation before moving to neural approaches.

## 🏗️ Model Details

### 1. Tokenization

- Character-level tokenization for simplicity and full interpretability
- Vocabulary $\mathcal{V}$ constructed directly from the dataset — no external tokenizer needed

### 2. Bigram Count Matrix

For every consecutive character pair $(x_{i-1}, x_i)$ in the corpus, we accumulate counts into a matrix $C \in \mathbb{Z}^{|\mathcal{V}| \times |\mathcal{V}|}$:

\text{count of } (x_{i-1}, x_i) \text{ in corpus}

Example count matrix:

|       | **a** | **b** | **c** |
|-------|:-----:|:-----:|:-----:|
| **a** |  10   |   5   |   2   |
| **b** |   3   |   8   |   1   |
| **c** |   0   |   2   |   6   |

- **Rows**: previous token $x_{i-1}$  
- **Columns**: current token $x_i$

### 3. Probability Estimation

Each row of $C$ is normalized to produce conditional probabilities:

$$P(x_i \mid x_{i-1}) = \frac{C[x_{i-1},\, x_i]}{\displaystyle\sum_{x} C[x_{i-1},\, x]}$$

This gives a row-stochastic probability matrix $P \in [0,1]^{|\mathcal{V}| \times |\mathcal{V}|}$:

|       | **a** | **b** | **c** |
|-------|:-----:|:-----:|:-----:|
| **a** | 0.59  | 0.29  | 0.12  |
| **b** | 0.25  | 0.67  | 0.08  |
| **c** | 0.00  | 0.25  | 0.75  |

### 4. Text Generation

Starting from a seed token $x_0$, text is generated autoregressively by sampling from the learned distribution at each step:

$$x_i \sim P(\cdot \mid x_{i-1}), \quad i = 1, 2, \ldots, T$$

The full pipeline:

```
Raw Text → Tokenization → Count Matrix C → Probability Matrix P → Sampling → Generated Text
```

### 5. Loss — Negative Log-Likelihood

Model quality is measured by the average negative log-likelihood over the corpus:

$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log P(x_i \mid x_{i-1})$$

A lower $\mathcal{L}$ indicates the model assigns higher probability to the observed sequences.

## 📉 Limitations

- **Markov order** $= 1$ — only the single preceding character is used as context
- **No semantic understanding** — purely statistical; no meaning is captured
- **Struggles with long-range dependencies** — cannot learn grammar or structure beyond adjacent characters
- **Sparse counts** — rare character pairs yield unreliable probability estimates without smoothing

---

## 🔬 Future Work

This implementation is a stepping stone. Meaningful extensions include:

| Extension | Description |
|---|---|
| Higher-order $n$-grams | Use $n > 2$ characters of context: $P(x_i \mid x_{i-n+1}, \ldots, x_{i-1})$ |
| Smoothing | Laplace / Kneser-Ney to handle zero-count bigrams |
| Neural LM | Replace the count matrix with a learned embedding + MLP |
| Transformer | Mini GPT-style self-attention for full sequence context |
