Overview
This project implements a Bigram Language Model using character-level tokenization. The model learns the probability of each character given the previous character, then uses that distribution to autoregressively generate new text.
The bigram assumption factorizes language as:
P(x₁, x₂, ..., xₙ) = ∏ᵢ₌₁ⁿ P(xᵢ | xᵢ₋₁)
Each token depends only on the immediately preceding token — simple, interpretable, and a great foundation before moving to neural approaches.

🏗️ Model Details
1. Tokenization

Character-level tokenization for simplicity and full interpretability
Vocabulary constructed directly from the dataset (no external tokenizer needed)

2. Bigram Count Matrix
Frequency counts are computed for all character pairs and stored in a matrix:
abca1052b381c026

Rows: previous token (xᵢ₋₁)
Columns: current token (xᵢ)

3. Probability Estimation
Counts are normalized row-wise to obtain conditional probabilities:
P(xᵢ | xᵢ₋₁) = Count(xᵢ₋₁, xᵢ) / Count(xᵢ₋₁)
Example probability matrix:
abca0.590.290.12b0.250.670.08c0.000.250.75
4. Text Generation
Text is generated autoregressively. At each step, the next character is sampled from the learned bigram distribution:
Raw Text → Tokenization → Count Matrix → Probability Matrix → Sampling → Generated Text

📉 Limitations

Markov order = 1 — only the immediately preceding character is used as context
No semantic understanding — purely statistical, no meaning captured
Struggles with long-range dependencies — cannot learn grammar or structure beyond adjacent characters


🔬 Future Work
This implementation is a stepping stone. Meaningful extensions include:

Higher-order n-gram models (trigrams, 4-grams) for richer context
Smoothing techniques (Laplace, Kneser-Ney) to handle unseen bigrams
Transition to neural language models (RNNs, LSTMs)
Implementing a mini GPT-style transformer for comparison
